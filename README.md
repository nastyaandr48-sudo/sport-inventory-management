📝 Описание проекта
Данная система предназначена для автоматизации процесса аренды спортивного инвентаря и управления бронированием залов. 
Основные функции:
• Ведение базы оборудования и залов.
• Контроль статуса инвентаря (свободен/выдан).
• Учет расписания залов для исключения накладок по времени.
• Регистрация клиентов.
